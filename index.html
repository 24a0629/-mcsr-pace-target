Each value is the split time at which the chance of hitting the target crosses that level.

Out of reach = “slower than this, the target is very unlikely to be reached”. Resets in Ranked are mostly decided by your state (an unrecoverable death or mistake), not by time: use this as a gauge of how far behind the target you are, not as a rule to reset.

Reset = “slower than this, the target is nearly impossible”. Continue if the previous split is under it; consider resetting if it is over.

Selection bias: only finished runs are counted. In Ranked a match ends when the opponent finishes, so slower runs are cut off and missing: success rates tend to run slightly optimistic and thresholds slightly lenient.

Selection bias: only finished runs are counted, so runners who reset early are missing and reset lines tend to run slightly strict. The numbers here come from MCSR Ranked matches (set seeds, no resets): treat them as an approximation for RSG.

— = no data. “none” = the probability never drops below the threshold.

各列の値は「そのスプリットをこの時間で抜けたなら、目標達成確率がその列のレベル以上」を意味する。

目標に届かない = 「これより遅いと、目標達成はほぼ見込めない」の目安。Rankedのリセットは、時間よりも、取り返しのつかない死亡やミスなど自分の状態で決めることが多いので、リセットの基準ではなく、目標からどれだけ遅れているかを知る参考として使う。

リセット = 「これより遅いと目標達成はほぼ不可能」の目安。直前のスプリットがこれより速ければ続行、超えたらリセット検討。

バイアス: 完走者のみのデータ。Rankedでは相手が完走すると試合が終わるため、遅い走りは途中で打ち切られてデータに残らず、達成確率はやや楽観的、閾値はやや緩めに出る傾向がある。

バイアス: 完走者のみのデータなので、早めにリセットした走者が含まれず、リセット閾値はやや厳しめに出る傾向がある。数字はMCSR Rankedの試合(同じシード・リセットなし)から計算しているため、RSGでは近似として使うこと。

— はデータなし。「なし」は確率が閾値を下回らないという意味。

Bar (pXX) = rank among runs that hit the target in the same period; p100 is fastest. For finish (PB), if the PB is above the target the bar is hidden and the shortfall is shown.

バー (pXX) = 同期間の目標達成者内での順位。p100 が最速。finish (PB) は PB が目標を超えている場合、バーの代わりに不足分を表示する。

Bias correction偏りの補正

Use runs that did not finish (recommended). In Ranked a match ends when the opponent finishes, so finisher-only numbers are optimistic; this corrects for the cut-off runs (Kaplan–Meier).完走しなかった人も使う(おすすめ)。Rankedでは相手が完走すると試合が終わるため、完走者だけだと楽観的になる。打ち切られた走りを統計手法(カプラン・マイヤー法)で補正する。
Count forfeits as failures. Off (default): a player who forfeits is treated like a cut-off run. On: the forfeiting player is assumed never to finish. Forfeits often follow a death and can be a speed-first gamble, so this is not always a failure.棄権を失敗として数える。オフ(初期値): 棄権した人も、打ち切られた走りと同じ扱い。オン: 棄権した人は完走しなかったものとして数える。棄権は死亡後に勝利を断念して行うことが多く、速度重視の結果でもあるため、必ずしも失敗とは言えない。

Tidy display表示の整え方

Show “none” instead of the cap value when the chance never drops below the threshold (recommended).確率が閾値を下回らないとき、上限の値ではなく「なし」と表示する(おすすめ)。
Keep each column increasing down the table (a later split is never earlier than the previous one). Can hide noise.各列が上から下へ小さくならないようにそろえる(前の区間より早い時間にならない)。ばらつきを隠すことがある。
