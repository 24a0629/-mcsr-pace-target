Target time = the finish time you are aiming for (sub-X).

Reset strategy = how strict each split’s reset line is: strict early (cheap to redo), lenient late (more time already invested).

Filters narrow the data to one season, start type or bastion type. Small samples show in parentheses.

目標タイム = 完走したい時間(sub-13 など)。

リセット戦略 = 各スプリットの切り捨て基準。序盤は厳しく(やり直しが安い)、終盤は緩く(投入時間が大きい)。

絞り込みでシーズン・スタート形態・バスチオンタイプ別のデータを見られる。サンプルが少ない値は括弧つきで表示。

Each value is the split time at which the chance of hitting the target crosses that level.

Reset = “slower than this, the target is nearly impossible”. Continue if the previous split is under it; consider resetting if it is over.

Selection bias: only finished runs are counted, so runners who reset early are missing and reset lines run slightly strict. — = no data.

各列の値は「そのスプリットをこの時間で抜けたなら、目標達成確率がその列のレベル以上」を意味する。

リセット = 「これより遅いと目標達成はほぼ不可能」の目安。直前のスプリットがこれより速ければ続行、超えたらリセット検討。

バイアス: 完走者のみのデータなので、早めにリセットした走者が含まれず、リセット閾値はやや厳しめに出る。— はデータなし。

Compare with runnerランナーの記録と比較

Median = the runner’s typical split over finishes in the period. The line under it is the difference from the Standard column (+ = slower than target pace).

Bar (pXX) = rank among runs that hit the target in the same period; p100 is fastest. For finish (PB), if the PB is above the target the bar is hidden and the shortfall is shown.

中央値 = 期間内の完走を対象にした、普段のスプリット。下の行は「標準」列との差(+ は目標ペースより遅い)。

バー (pXX) = 同期間の目標達成者内での順位。p100 が最速。finish (PB) は PB が目標を超えている場合、バーの代わりに不足分を表示する。
